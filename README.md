🎙️ VoxMate AI – Your Smart Voice Assistant

🤖 Your Personal AI-Powered Voice Task & Productivity Assistant

VoxMate AI is an intelligent AI-powered voice assistant designed to make everyday productivity easier and smarter.

It allows users to interact with an AI assistant, manage daily tasks, create notes, and get AI-powered responses through a simple and modern interface.

Think Less. Speak More. Stay Productive! 🚀

---

✨ Project Overview

VoxMate AI is a Full Stack AI application that combines voice interaction, task management, note-taking, and artificial intelligence in one platform.

The main objective is to help users organize their daily activities and manage information more efficiently using AI.

---

🔥 Key Features

- 🎤 Voice Interaction: Interact with the assistant using your voice.
- 🤖 AI Chat Assistant: Get intelligent AI-powered responses.
- ✅ Task Management: Create, manage, and organize daily tasks.
- 📝 Smart Notes: Create and save personal notes.
- 🔐 User Authentication: Secure signup and login functionality.
- 📊 Productivity Management: Keep your daily activities organized.
- 💬 AI Conversations: Chat with your personal AI assistant.
- 🎨 Modern UI: Clean and responsive user interface.

⚙️ Installation & Setup

1. Clone Repository

git clone https://github.com/ajit9129353710/VOXMATE-AI.git

2. Navigate to Project

cd VOXMATE-AI

3. Backend Setup

cd backend
npm install

Create a ".env" file inside the backend folder.

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key

Start Backend:

npm run dev

4. Frontend Setup

Open another terminal:

cd frontend
npm install

Create a ".env" file:

VITE_API_URL=http://localhost:5000

Start Frontend:

npm run dev

---

🔒 Security

- JWT-based user authentication.
- Secure API endpoints.
- Environment variables for sensitive credentials.
- MongoDB database connection security.
- API keys are not exposed in public repositories.

Never upload your ".env" file to GitHub.
